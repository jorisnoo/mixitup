MixItUp Demos

These demos use the ESM build of the MixItUp fork in this repository. Each page contains its own markup, styles and initialization code.

From the repository root, run python3 -m http.server --bind 127.0.0.1 and open http://127.0.0.1:8000/demos/ in a modern browser. The interactive examples load the local dist/mixitup.js bundle; no external scripts or package installation are required.
